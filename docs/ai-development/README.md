# Sprival AI辅助开发文档规范

## 概述

本文档规范旨在为sprival项目的AI辅助开发提供标准化的文档结构、上下文管理策略和提示词模板，确保AI助手能够高效、准确地理解项目需求并提供开发支持。

## 项目背景

Sprival是一个Spring Boot组件集成模板项目，提供：
- 全面的pom.xml组件引入
- 各个组件配置使用说明
- 监控指标方案
- K8s部署方案
- ELK日志集成方案
- Prometheus监控集成方案

## 核心组件模块

### 已集成组件
1. **http-server**: Jetty Web服务器 + Guava RateLimiter接口限流
2. **spring-mysql**: MyBatis-Plus + Dynamic-Datasource + HikariCP + P6Spy
3. **spring-data**: Kafka + MongoDB + RabbitMQ + Elasticsearch (Spring官方组件)
4. **spring-redis**: Spring Cache + Spring Data Redis + Redisson
5. **spring-clickhouse**: ClickHouse集成到MyBatis-Plus

### 待完善组件
- **http-client**: HTTP客户端、熔断器、重试器、负载均衡器

## 使用指南

### 开发者使用流程
1. 阅读本规范文档
2. 根据任务类型选择合适的模板
3. 提供完整的上下文信息
4. 使用标准化的问题描述格式
5. 验证AI输出结果
6. 更新相关文档

### AI助手使用建议
1. 优先查阅项目文档获取上下文
2. 理解组件间的依赖关系
3. 遵循项目的编码规范和架构模式
4. 提供可执行的代码和配置
5. 及时更新相关文档
