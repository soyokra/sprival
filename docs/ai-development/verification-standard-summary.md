## 🎯 验证规范要点

### 核心原则
1. **及时验证**: 每次修改后立即验证
2. **全面验证**: 包括编译、启动、健康检查、监控指标
3. **问题追踪**: 记录问题并积累解决方案

### 验证步骤
1. **编译验证**: `mvn clean compile`
2. **启动验证**: 检查应用是否成功启动
3. **健康检查验证**: 验证各组件健康状态
4. **监控指标验证**: 检查监控端点是否正常

### 自动化工具
```powershell
# 完整验证
.\scripts\verify-code-changes.ps1

# 跳过启动验证（仅编译）
.\scripts\verify-code-changes.ps1 -SkipStartup -SkipHealth

# 详细输出
.\scripts\verify-code-changes.ps1 -Verbose
```

## 🔧 使用指南

### 开发人员使用
1. 修改代码后运行验证脚本
2. 根据验证结果修复问题
3. 记录验证结果和问题解决方案
4. 提交代码前确保所有验证通过

### AI开发使用
1. 生成代码后自动运行验证
2. 根据验证结果调整代码
3. 确保生成的代码符合项目标准
4. 提供验证结果给用户
