# 更新日志

## v1.0.0 (2025-11-03)

### 🎉 首次发布

完整的 Python REST API 接口测试框架，包含以下核心功能：

#### 核心模块

- **Mock 数据生成**: 支持字符串、数字、日期、复杂对象等多种数据类型生成
- **HTTP 客户端**: 基于 requests 封装，支持重试、超时、连接池
- **响应处理**: 强大的响应验证和数据提取功能
- **场景测试**: 支持恒定、渐进式、峰值、波浪式等多种负载模式

#### 测试场景

- **Constant**: 恒定负载，固定线程数持续运行
- **Ramp Up**: 渐进式压测，从初始值逐步增加到目标负载
- **Spike**: 峰值冲击，瞬间达到峰值负载
- **Wave**: 波浪式负载，周期性变化

#### 报告系统

- **Console**: 实时彩色控制台输出
- **JSON**: 机器可读的结构化报告
- **HTML**: 美观的可视化报告

#### 配置管理

- **JSON 配置**: 支持 JSON 配置文件
- **命令行参数**: 灵活的命令行参数
- **Schema 验证**: 配置文件验证

#### 快速命令

- `smoke_test`: 冒烟测试
- `stress_test`: 压力测试
- `stability_test`: 稳定性测试
- `spike_test`: 峰值测试
- `wave_test`: 波浪测试

#### 文档

- 完整的 README 和快速开始指南
- 详细的 API 参考文档
- 丰富的示例代码

### 特性

- ✅ 智能数据 Mock，支持模板语法
- ✅ 多线程并发测试
- ✅ 复杂场景模拟
- ✅ 实时性能监控
- ✅ 多格式报告输出

- Python 3.8+
- requests (HTTP 客户端)
- jinja2 (HTML 模板)

- colorama (彩色输出)
- numpy (统计计算)
