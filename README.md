## 关于 Sprival

Sprival是一个AI协同工作构建的Spring Boot集成框架，旨在提供一份标准项目构建配置，组件集成，中间件集成，ELK日志集成，监控集成，云原生部署方案。

### 组件集成
- http server
- http client

### 中间件集成
- mysql
- redis
- rabbitmq
- kafka
- elasticsearch
- clickhouse

### ELK日志
- kafkaAppender
- elk

### 监控集成
- grafana
- prometheus
